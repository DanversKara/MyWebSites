Features BearerMail additions

What the fork adds on top of upstream plMail. For everything plMail itself does — accounts, calendar, filters, themes — the upstream handbook remains the reference.

Drive

Personal file storage built into the webmail, Google-Drive-style: grid and list views, folders, file-type icons, search, and drag-and-drop upload. Files live in the app_drive volume (/app/var/drive inside the app containers) and are included in app:backup.

  • Folders — nested folder tree, rename, move, delete.
  • Uploads — drag-and-drop or picker, with progress. Up to 2 GB per file from the web (the admin can set a lower limit).
  • Storage — 5 GB per person by default; the admin sets the default and per-person limits (see Admin → Drive).
  • Compose integration — the compose toolbar's Insert file from Drive drops a download link into the message instead of a heavy attachment.
  • Too big to attach → Drive link new — attach a file that is over the mail size limit and it is uploaded to your Drive automatically, with a download link and a short note put in the message, instead of failing at Send. Works on the web and in the app.
  • Calendar integration — Add from Drive under an event's description puts a file's share link into the event.

Share links

Any file can get a public download link: ⋯ → Share. Each link can have:

  • an optional password (visitors must enter it; wrong guesses are rate-limited),
  • an optional expiry date (the app offers 1, 7 or 30 days, or never),
  • a download counter, and a Report this link button for recipients.

Shared links open a proper page — the file with a Download button — not a raw download. Manage or revoke links from the file's share dialog; expired links stop working on their own.

Reported links

Anyone who was sent a link can report it (spam, malware, phishing, illegal content, copyright, something else), with optional details and an optional email address.

  • They see a thank-you page; if they left an address, they also get a confirmation email.
  • Every administrator gets an email with the file, the reason and a link to Admin → Drive.
  • Clicking Report again from the same address within 24 hours counts once, and one network can file at most 5 reports an hour.

Report emails are sent from an administrator's own mailbox, so at least one admin needs a mail account in BearerMail.

Admin → Drive new

  • Drive limits — storage per person (0 = no limit) and the largest single file.
  • Storage by person — who uses how much, an own limit per person, and a switch to turn Drive off for someone who abuses it. Turning it off also stops every link that person has shared. The same two settings are on each user's edit form under Admin → Users.
  • Reported links — each open report with three actions: Revoke link, Switch off owner's Drive, or Dismiss.
Security note

Share links are bearer URLs: anyone with the link can download (plus the password, if you set one). Don't put anything sensitive behind an unprotected link, and prefer short expiries for one-off shares.

On-the-spot aliases

Create a working email alias in one tap — no admin, no waiting. In the web UI: Settings → Aliases → New alias, or straight from the composer's From menu.

  • Type a name (shop@yourdomain.com) or generate a random one (shop.k3v9x2ma@yourdomain.com).
  • The address is live within seconds — the mail server picks it up automatically — and you can select it as the From address immediately.
  • Delete it any time under Settings → Aliases.

Handy for signups: one alias per service, and when the spam starts you know exactly who sold your address — then delete just that alias.

Plans and codes found in your mail new

BearerMail reads incoming mail for two kinds of things and shows them as a card at the top of the message, on the web and in the app.

  • Plans — "meet me at 218 Main St on Friday at 10am", "lunch tomorrow at 12:30". The card shows the date, time and place with Add to calendar (opens the event editor pre-filled; nothing is saved until you press Save) and Not an event. Addresses that wrap onto two lines are read whole. Header lines in forwarded or quoted mail ("Date: …", "On … wrote:") and sign-in or password-reset mails are never treated as plans.
  • Verification codes — "enter the following code: 959528". The card shows the code with Copy code. A code word has to stand next to the number, so order numbers, prices and years are left alone. Codes in forwarded mail are found too.
  • Insert event in compose — the composer's Insert event picks one of your upcoming events, writes its details into the message and attaches it as an .ics, so the recipient adds it to their calendar in one tap.

Cards are made when mail arrives. To re-read mail that arrived before an update, run docker compose exec php php bin/console app:backfill insights --since=YYYY-MM-DD; a re-read replaces that mail's old code and plan cards.

Notes new

Notes in the style of Google Keep, on the web (Notes in the top bar, or /notes) and in the Android app (Drawer → Notes). Both work on the same notes, so a note typed on the phone is on the web a moment later, and the other way round.

Writing

  • Saves as you type — there is no Save button. Undo and Redo step back and forward through what you typed.
  • Checklists — the checkbox button turns a note into a list. Tick items off in the note or straight from its card; press Enter for the next item.
  • Formatting — bold, italic, underline, headings and bullet lists from the toolbar. The marks are plain text (**bold**, *italic*, __underline__, a line starting # or - ), so the web and the phone show the same thing.
  • Colours, labels, pin, archive, bin — ten Keep colours; labels separated by commas (click one to see only those notes); pin to the top; archive to put away; the bin keeps a note until you delete it forever.
  • Search — the search box finds text in titles, notes, checklist items and labels.

Notes on contacts and events

Open a contact or a calendar event and its Notes section lists the notes linked to it, with Add note to write a new one already linked. In a note, the link button links it to a contact or an event; the link shows on the note and opens that contact or day.

Reminders

The bell in a note's toolbar sets a reminder: Later today, Tomorrow morning, Next week, or your own date and time. When it is due, BearerMail sends you an email (from and to your own mailbox) and a notification to every device you allowed notifications on — on Android on the Reminders channel, with sound, and tapping it opens the note. The reminder shows as a bell chip on the note and its card, crossed out once it has gone; the ✕ removes it.

A reminder is sent once. If the server was down when it was due, it still goes out up to an hour late; after that it is skipped rather than arriving hours late.

Share links and collaborators

A note's Share & download section makes a link (https://your-server/n/…) that opens the note for someone without an account:

  • Password (optional) — visitors type it first; wrong guesses are rate-limited.
  • Expiry — never, 1 day, 7 days, 30 days or 1 year.
  • Collaborators — tick Let people with the link edit and whoever has the link can change the title, the text and the checklist; their changes save as they type.
  • Each link shows whether it can edit, has a password, when it expires and how often it was opened, with Copy link and delete.

Shared notes show their pictures, drawings and voice notes too.

Download, send and insert

  • Download .txt — the title and the text (a checklist as [x] / [ ] lines).
  • Download .png — a picture of the note card in its colour.
  • In an email — the compose window's template picker has a Notes group; picking one puts the note into the message. In the app: compose menu (⋯) → Insert note.
  • On the phone — the share button sends a copy as text, shares it as a picture, or saves it as a .txt file.

Pictures, drawings and voice notes

  • Pictures — the picture button adds one or several images. They show across the top of the note and on its card; click one to open it full size.
  • Drawing — the paintbrush opens a drawing pad: six colours and an eraser, pen size, undo and clear. Save drawing adds it to the note.
  • Voice notes — the microphone records until you press it again (at most five minutes); the recording plays under the pictures. The browser (or phone) asks to use the microphone the first time.
  • Up to 30 per note; 15 MB a picture, 10 MB a drawing, 25 MB a recording. The files are kept on the Drive volume and go with the note when it is deleted forever.

App icon and logos new

Settings → Appearance:

  • App icon — the picture for the web portal's browser tab and top bar: one of the plMail logos, or the BearerMail envelope.
  • Logo — the icons that go with that choice. With the plMail logos: ten logos, each in its own colours, the theme's, or one of thirty-two colourways. With BearerMail: the BearerMail Android icon in Navy or White.
  • The Android app's home-screen icon follows the Logo choice on its next sync.

Account health

Settings → Account health answers "why has my mail stopped?" and, where it can, gives you the button that fixes it. It reads what the server already recorded and never contacts Google or any other provider, so opening it is free.

  • The top bar points at it with a dot when there is a problem.
  • It covers your own accounts only. Admins see every user's sign-in and push problems on the Admin dashboard (token health, push and worker status).

Mail-server admin

  • Mailboxes for new people new — Admin → Users → New user has a Mailbox field: fill it in and that person gets a mailbox on your domain with their starting password, already added as their mail account — they can send and receive the first time they sign in, with no container restart. From the shell: app:mail:mailbox (see Managing mailboxes).
  • Admin → Mail server — configure the outbound SMTP relay (host, username, secret) from the UI; the MTA picks it up within seconds, no rebuild. Clearing the host returns to direct delivery.
  • DNS checker — verifies your MX/SPF/DKIM/DMARC records from the admin area.
  • DMARC report parsing — aggregate reports land in a readable view instead of raw XML.
  • Public IMAP — port 993 with TLS, so any mail app can connect directly to your domain mailboxes.

Security extras

  • Mail login blocking new — see below.
  • Single sign-on new — sign in to the webmail through Authentik, Keycloak or another OpenID Connect provider. See Single sign-on.
  • Forged-sender warnings — banners on messages whose From doesn't match the authenticated sender.
  • Deceptive-link warnings — flags when a link's display text doesn't match its target.
  • SMTP keys — per-device SMTP credentials you can create and revoke, instead of sharing your mailbox password with every client.
  • Flood-protection banner and security monitoring in the admin area.

Mail login blocking

Password guessers on the internet try mailbox passwords against IMAP (port 993) over and over. BearerMail counts wrong passwords per internet address and blocks an address that has too many: while it is blocked, even the right password is refused from it. It is built into the mail server — no fail2ban, no firewall changes.

  • Defaults: 10 wrong passwords within 60 minutes blocks the address for 24 hours. Change all three, or switch it off, under Admin → Security → Mail login blocking (block time 0 = until you unblock it).
  • Unblock or Unblock and always allow any blocked address in one click, and add your home or office address to Always allowed. Addresses that are failing but not blocked yet are listed too.
  • Each block also appears under Recent security events.
  • Never counted: the web app and the phone app (they don't use port 993), devices on your home network, Docker's own addresses, and always-allowed addresses.
  • Can't lock you out: if BearerMail itself is down, mail logins go through as before — the blocking switches off, it never blocks everyone.

To turn it off entirely, put MAIL_LOGIN_GUARD=off in .env.mail.local and restart the mail containers.

From upstream plMail v0.3.5 merged

BearerMail keeps up with karatektus's plMail. The latest merge brought in, among 60 changes:

  • Single sign-on through OpenID Connect (Authentik, Keycloak…) — BearerMail adds two switches on top, see Single sign-on.
  • Replies from the right address — answering a mail sends from the address it came in for, catch-all addresses included, under that address's name. Signatures can be formatted.
  • Unread counts on the inbox tabs (with a setting to turn them off) and in the browser tab title.
  • Disposal setting — the Delete forever buttons are hidden unless you switch them on.
  • Account colours for connected Gmail and Microsoft accounts.
  • More AI hosts — OpenAI-compatible endpoints as well as Ollama, with a separate host for search by meaning.
  • Reliability — live IMAP connections reconnect when the server drops them, stuck connections are closed after five minutes, and signing out now holds on every device (remember-me tokens live on the server).
  • Gmail imports respect Google's quota and show a live messages-per-minute figure.
  • Card fixes — re-reading old mail no longer overwrites newer parcel cards; Outlook mail is read in full.

Android-only extras

The Android app has its own set of additions: home-screen widgets for the calendar and notes, one-tap verification-code copying from notifications, an app PIN lock, crash reports and a built-in updater. See the app page for the full list.
