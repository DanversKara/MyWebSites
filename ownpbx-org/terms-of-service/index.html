2. What OwnPBX is

In plain language: OwnPBX is software, not a phone company. It does not provide phone service by itself — it connects to a PBX server you run or administer.

OwnPBX is free, open-source software (GPL-2.0-or-later) for running your own private branch exchange: calls, texts, voicemail, and push-to-talk between extensions, plus PSTN connectivity where the server's administrator has configured telephone trunks. The My Phone app is a client for that server. OwnPBX is not a carrier, does not assign public phone numbers by itself, and does not guarantee connectivity to any public network — that depends on the server's trunks and carriers.
